## NEO-BRUTALIST waves (36 waves, approved 09:41, P0 first)

### W1 finding (quest-grid audit)
- Base .qcard was height 126px + overflow:hidden, so the bottom row of a
  quest card was genuinely clipped when the title wrapped or the card
  narrowed. MAJOR already set height:auto, but .qcard-body kept
  overflow:hidden and .qcard-desc kept a 2-line clamp, so long text
  could still be cut. The screenshot crop alone was not proof, but the
  fixed-height + hidden-overflow combination was a real clipping cause.
- Fix (P0): cards grow to fit content, body overflow visible, title
  and description wrap in full, grid 3/2/1, Done grid 3/row.

### P0 (W1-W6)
- Quest grid desktop 3/row, tablet 2/row, mobile 1/row, no horizontal
  scroll; cards fully rounded (20px) with hard shadow; Done grid in
  the same card language; empty/loading states restyled, never blank.
