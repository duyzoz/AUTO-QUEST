## Waves 25 — Thanh nạp đứng im (CSS) + phân loại 3 tab sai 100%

### Gốc rễ 1: `prefers-reduced-motion` giết sạch animation
`styles.css` có `@media (prefers-reduced-motion: reduce) { *, *::before, *::after {
animation-duration:.01ms !important; ... } }`. Windows tắt "Show animations" →
Chromium báo `reduce` → **mọi** animation chết (thanh nạp, snake, ring) ⇒ đúng
triệu chứng "0% rồi nhảy 100%".
**Fix**: bỏ selector `*`; chỉ tắt hiệu ứng trang trí; GIỮ tín hiệu tiến trình
(`.snake-spin` 1.6s, `.ll-bar::before` 2.4s, `.ll-bar > i` 3s).
Đo bằng `Emulation.setEmulatedMedia` → width 42.32% → 46.2% → 47.7% (moving).

### Gốc rễ 2: event dồn cục
Quét 27 quest xong trong ~80ms. **Fix kép**: bot `sleep(24)`/quest + renderer
thanh nạp tự chạy bằng **rAF** (`loaderTick`, bò ≥0.6%/frame, chờ bot bò
0.1%/frame) + giữ loader **tối thiểu 900ms** rồi mới fade.

### Gốc rễ 3: 3 tab phân loại SAI
Repo gốc `Discord-Auto-Quests/src/engine.ts` dùng 3 cờ độc lập: `completed_at`,
`enrolled_at`, `claimed_at`; `claimable() = completed && !claimed`.
Code cũ map `new`(chưa enroll) → tab "Chưa nhận" ⇒ toàn quest rác/hết hạn.
**Fix**: `status = 'todo' | 'claimable' | 'claimed'`
- `todo` = !completed → **Chưa làm**
- `claimable` = completed && !claimed → **Chưa nhận**
- `claimed` = completed && claimed → **Đã làm**
Thêm event riêng `quest:claim` (redeemQuest) để thẻ đi đúng đường 3 bước.
Đo thật 20 quest: **4 chưa làm · 3 chưa nhận · 13 đã nhận** — 3 cái chưa nhận
đúng là 3 avatar decoration (Acolyte Survivor, Champions Shanghai, Kung Fu Coach).
